# Hospital Reviva — versão com a nova logo

## Como publicar
1. Extraia o ZIP.
2. Abra o repositório do GitHub.
3. Apague os arquivos antigos.
4. Envie todos os arquivos e a pasta `assets`.
5. Clique em **Commit changes**.
6. Aguarde alguns minutos e atualize a página.

## Estrutura correta
- index.html
- style.css
- main.js
- privacidade.html
- robots.txt
- sitemap.xml
- assets/
  - images/
  - logo/
  - icons/

## Importante
O arquivo `index.html` deve ficar na primeira tela do repositório, e não dentro de outra pasta.
